# Endrick - Protótipo Interativo

Este é um protótipo de portfólio interativo focado na trajetória do jogador Endrick. O projeto utiliza **HTML**, **CSS** e **JavaScript** puro (Vanilla) aliado à biblioteca **GSAP** (GreenSock Animation Platform) e seus plugins (ScrollTrigger, ScrollToPlugin) para criar animações complexas, transições de rolagem contínua, efeitos parallax e ancoragem de elementos visuais.

## Tecnologias Utilizadas
- **HTML5 & CSS3:** Estruturação semântica e estilização com efeitos visuais avançados (recortes de imagem, misturas de cores com mix-blend-mode, text-strokes).
- **JavaScript (Vanilla):** Lógica de animações e manipulação do DOM.
- **GSAP & ScrollTrigger:** Para controle super preciso das animações baseadas no scroll da página, como a pinagem de seções (pinning), rotação de modelos 3D (vídeos transparentes) e passagens laterais.

## Como Executar
O projeto não exige nenhum build ou bundler complexo (como Node.js, Webpack, etc.). Para visualizar:

1. Clone ou faça o download deste repositório.
2. Utilize uma extensão como **Live Server** (no VS Code) ou rode um servidor HTTP local simples (ex: `python -m http.server`) na pasta raiz do projeto.
3. Acesse no seu navegador de preferência.

*(O uso de servidor local é fortemente recomendado para evitar bloqueios de segurança "CORS" dos navegadores ao tentar ler arquivos locais, como os vídeos utilizados no projeto).*
